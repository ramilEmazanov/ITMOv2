# Презентация для сдачи практики 7.1

Откройте `index.html` в браузере. Презентация работает без интернета; внешняя ссылка ведёт на тестовый PR.

- Стрелки ← / → и пробел — переключение слайдов.
- F — полный экран, если поддерживается браузером.
- «Печать / PDF» — печать всех слайдов.
- Экспорты из `workflows/` доступны по ссылкам внутри презентации. При передаче сохраните структуру всей папки.

## Скриншоты для добавления

Положить изображения в `assets/`, затем заменить соответствующий блок `figure.evidence` изображением с подписью.

| ID блока | Подтверждение |
|---|---|
| `evidence-base-workflow` | Схема первого сценария без точечных комментариев |
| `evidence-second-model` | Execution второй модели и опубликованное ревью |
| `evidence-data-table` | Строка PR в reviewed_prs |
| `evidence-dedup` | Повторный /make_ai_review: 0 items на проверке таблицы |
| `evidence-inline-workflow` | Схема второго сценария с Parse Hunks и Build Inline Review |
| `evidence-inline-comments` | Комментарии у блоков кода на Files changed и успешный Execution |

Содержание описывает приложенные JSON. До добавления скриншотов реальные запуски не считаются подтверждёнными.
