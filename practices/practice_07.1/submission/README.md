# Презентация для сдачи практики 7.1

Откройте `index.html` в браузере. Стрелки ← / → и пробел переключают слайды, F включает полный экран. Кнопка «Печать / PDF» печатает все слайды. Скриншоты открываются в полном размере по нажатию.

## Порядок

1. Титульный слайд.
2. Ссылки на JSON и PR #6 / PR #5.
3. Подключённые модели OpenCode Go и Base URL.
4–9. Базовая версия, PR #6: схема, основная модель и ответ, вторая модель и ответ, Data Table, остановленный повтор, повторная команда без нового ревью.
10–14. Точечная версия, PR #5: раздел, основная и вторая ветки с результатами, Data Table, проверка повтора.
15. Вычисление диапазонов строк.

Изображения из `assets/base/` и `assets/extended/` сохранены без изменений. Файл `extended/extendedBase.png` содержит схему без Parse Hunks и Build Inline Review, поэтому не используется как схема точечного workflow.

## Подтверждения повторных запусков

На слайде 6 добавлен `base/baseOtherWorkflow.png`. На слайде 14 — `extended/extendedWorkflowSkip.png` и `extended/extendedWorkflowSkipComment.png`: остановка на проверке таблицы и повторная команда в PR #5.

При передаче локальной презентации сохраните папку `assets/`. Оба JSON также лежат в `workflows/`, ссылки презентации ведут на GitHub.

## Оформление

Тёмная адаптация лекции SOLID: локальный Golos Text, синий акцент `#0A3D91`, крупные жирные заголовки и широкие поля. Для читаемости на тёмном фоне текст ссылок использует светлый оттенок синего. Шрифты включены в `assets/fonts/`.
